# 金融指标工作台 F3 验证

本次在 Windows 上用浏览器和合成数据验证指标页。预览页使用和桌面端相同的图表、目录及设置解析，数据和设置存储由测试页提供。它不会启动 Tauri、运行金融引擎或访问正式版的数据库。

## 自动检查

在仓库根目录运行以下命令。Python 默认排除联网测试，Rust 的原生测试使用临时数据库和模拟子进程。

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm exec prettier . --check
uv run --project engines/finance --locked pytest engines/finance/tests
cargo test --locked --manifest-path apps/desktop/src-tauri/Cargo.toml --lib finance::tests
```

本地通过 154 个 Vitest、56 个离线 pytest 和 4 个 Rust 测试。图表快照检查月均、沪深300 副轴、默认阈值虚线和原始值模式。内存 SQLite 测试确认较前一交易日的变化遇到缺值时留空，避免跳过缺值比较更早的日期。

## 手动复现

1. 在仓库根目录的 PowerShell 启动浏览器预览。只启动下面的 Vite 命令。

   ```powershell
   pnpm --filter desktop exec vite ../.. --config vite.config.ts --host 127.0.0.1 --port 1432 --strictPort
   ```

2. 用浏览器的 InPrivate／无痕窗口打开 [合成数据预览](http://127.0.0.1:1432/workbenches/finance/tests/preview.html)。目录应显示「交易拥挤」「市场宽度」「估值」三组及最新值。点「前 5% 成交额占比」，确认默认日线、3 年范围、沪深300 叠加开启，45% 和 50% 有虚线。再点「60 日新高占比」，检查当前值和说明区随指标变化。
3. 切换 1 年、3 年、5 年、全部，拖动底部缩放条的两端。前两个指标的全部数据从 2015 年起。返回前 5% 指标并点「月均」，应看到每月一值，当前月标注「本月至今」。
4. 用图例关闭沪深300 叠加，再刷新页面。叠加应仍关闭，刚才的指标、月均和范围应保留。用工具栏重新打开叠加，右侧指数点位轴应恢复。预览用浏览器本地存储模拟重启后的设置读取。
5. 打开「指数估值分位」，将显示范围切到「全部」。依次选择 5 年、10 年、全部估值窗口，对比曲线和最早非空点。合成数据的起点分别是 2009-07-07、2014-01-07 和 2008-01-01。切换创业板指、上证指数及 PB，再切到「原始值」。原始值从 2005 年起，左轴显示原始估值。切回分位后，当前值卡片同时显示分位与原始估值。
6. 在地址末尾加 `?theme=dark`，检查曲线、虚线、提示框与坐标轴在深色背景下可读。分别访问 `?empty=1`、`?empty=1&busy=1`、`?error=1`，确认暂无数据、正在准备和读取错误都有各自的提示。
7. 验证结束后，在预览服务器的 PowerShell 按 `Ctrl+C`。

以上步骤在浏览器已通过。正式版正在回补期间，桌面运行、实际连接与安装版交互验收留待回补结束。

## F2 审查项

| 项目       | 实现与验证                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 测试连接   | 原生进程监控在 60 秒时发出取消信号，必要时再等最多 5 秒并终止进程树。Rust 用缩短的时限验证超时与取消流程。                                                                                                                        |
| 取消和退出 | 保留 PyInstaller 单文件包。引擎检查本次运行专用的取消文件，先尝试自行退出。每次运行把 `TEMP` 和 `TMP` 指向专用目录，原生端在进程结束后清理该目录。模拟子进程覆盖正常退出与目录回收，Python 离线测试覆盖取消后缓存快照和锁的状态。 |
| 引擎日志   | 将 stderr 中的凭据原文替换为遮盖字符后写入 Tauri 应用日志目录的 `finance-engine.log`。Rust 测试使用假凭据验证打码。                                                                                                               |
| 等待子进程 | `collect()` 取出 child 后释放状态锁再等待，保留运行占用标记，使等待期间仍可处理取消。                                                                                                                                             |
| SQL 权限   | 移除 WebView 的 `sql:allow-load` 和 `sql:allow-close`。主窗口通过专用原生命令打开固定位置的只读金融缓存。Rust 测试确认缺失文件时不会创建文件，已有文件可读且写入失败。                                                            |

## Vite 构建体积

同一台 Windows 机器上分别对 F2 的 `main` 和 F3 执行 `pnpm --filter desktop exec vite build`。首次加载大小按 `index.html` 引用的入口脚本和 `modulepreload` 脚本相加，gzip 逐文件压缩后相加。单位为十进制 kB。

| JavaScript       |                          F2 |                          F3 |
| ---------------- | --------------------------: | --------------------------: |
| 首次加载         | 1,029.6 kB（gzip 318.4 kB） | 1,031.6 kB（gzip 320.7 kB） |
| 金融图表独立分包 |                           — |   579.9 kB（gzip 193.6 kB） |

金融图表分包仅在打开金融工作台后加载。Vite 仍对超过 500 kB 的分包发出体积提示。
