# 备忘录阶段验证

本阶段实现综合工作台主框架、主题、备忘录和备忘录回收站。今天、日程、提醒事项为占位页；设置页本阶段提供主题选择。

## 开发与自动验证

在仓库根目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm exec prettier . --check
pnpm --filter desktop tauri dev
```

数据调用集中在 `workbenches/general/src/api.ts`，Phase 1 经已有 core 仓库访问 SQLite。主框架、Zustand 状态和编辑组件都不直接查询数据库。`initializeDataLayer()` 保持单例初始化，沿用启动时及每 24 小时一次的 30 天清理任务。

编辑器使用 Tiptap 官方 `@tiptap/markdown`。编辑器和格式往返测试共用扩展；测试检查节点、标记、文字、代码语言、有序列表起始编号和待办勾选状态，允许 Markdown 写法规范化。正文始终以 Markdown 写入 `memos.content`。图片和附件未启用。

自动保存队列在最后一次编辑后 500ms 写入，串行处理保存；旧结果不会覆盖保存期间的新输入。切换备忘录、页签或设置/回收站前立即提交并等待；保存失败时保留草稿并阻止切换。正常关闭窗口时，Shell 拦截关闭请求，等待保存成功再销毁窗口，失败则保留窗口供重试。强制结束进程不属于可拦截的正常关闭。

## Windows 手动检查

1. 启动后默认是“今天”。左侧可进入综合工作台、设置和回收站，四个页签按规格排列。
2. 打开备忘录并新建，输入中文标题和正文。停止输入约 500ms 后应显示“所有修改已保存”，无需点击保存按钮。
3. 用工具栏依次试标题、粗体、斜体、删除线、有序/无序列表、待办、引用、代码块和链接。勾选待办，再切换到另一条并切回，格式和勾选状态应保留。链接框拒绝 `javascript:` 等可执行地址。
4. 添加多个标签，回车确认；新建另一条后输入已有标签前缀，可点选建议或用 Tab 补全，也可用方向键和回车选择。置顶的备忘录应始终在前，其余按最后保存时间倒序。
5. 搜索标题、正文或标签，英文关键词不区分大小写。标签筛选可以与搜索叠加；无匹配时有空状态，清空搜索后列表恢复。无标题记录显示正文首行。
6. 输入后立即切换记录或页签，返回时内容应保留。正常关闭窗口，再次启动，检查正文格式、标签、置顶和主题仍保留。可把窗口缩小到 900×600，列表和编辑器应各自滚动，工具栏换行，页面无横向溢出。
7. 设置中分别选择跟随系统、浅色和深色。跟随系统时响应系统主题变化；明确选择浅/深色时保持所选主题。关闭重开后应保留选择。
8. 将自己创建的测试备忘录移至回收站，确认列表移除、回收站出现；恢复后内容和标签保留。回收站的日程、提醒分组目前标记“准备中”。
9. 对自己的测试记录检查“永久删除”确认框，取消应保留记录。确认永久删除后内容不可恢复；SQLite 单测验证它保留行和 `deleted_at`，只清空内容。30 天清理的严格时间边界沿用数据层单测。

按 F12 可检查控制台，正常流程不应出现数据库、CSP 或 React 错误。模板原有 `favicon.ico` 404 与本阶段功能无关。
