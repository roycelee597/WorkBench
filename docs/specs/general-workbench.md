# 综合工作台规格说明（v1）

> 状态：已确认（2026-11-04）。实现 Phase 1 时以本文件为准；与 ARCHITECTURE.md 冲突时，**本文件优先**（仅限综合工作台范围），并在 PR 中同步修订 ARCHITECTURE.md。

## 1. 定位

- 内置、不可卸载，id `com.royce.workbench.general`，是软件启动后的默认工作台。
- 不装任何插件也能完成日常管理：记事、排时间、到点提醒。
- Phase 1 直接调用 core 仓库，但所有数据调用集中在 `workbenches/general/src/api.ts`，Phase 2 换成 SDK。

## 2. 布局

- 左侧：工作台切换栏（目前只有综合工作台；底部放「设置」「回收站」入口）。
- 综合工作台内 4 个页签，顺序：**今天 / 备忘录 / 日程 / 提醒事项**，默认打开「今天」。
- 中文界面；浅色/深色主题，默认跟随系统。

## 3. 今天（总览页）

只读汇总 + 快捷操作，三个区块：

| 区块           | 内容                                                                   | 交互                           |
| -------------- | ---------------------------------------------------------------------- | ------------------------------ |
| 今天的日程     | 今天的全部日程（含重复日程展开出的实例），按开始时间排序；全天日程置顶 | 点击跳到日程页并选中           |
| 今天和逾期提醒 | `due_at` 在今天的未完成提醒 + 已逾期未完成提醒（逾期标红）             | 可直接勾选完成；点击跳到提醒页 |
| 置顶备忘录     | 所有 `pinned=1` 的备忘录卡片（标题 + 正文前 2 行）                     | 点击跳到备忘录编辑             |

- 区块为空时显示简短空状态文案，不隐藏区块。
- 跨过午夜时自动刷新（日期变化即重新查询）。

## 4. 备忘录

- 布局：左列表、右编辑区。
- 编辑器：**所见即所得**，使用 Tiptap；支持标题、粗体/斜体/删除线、有序/无序列表、待办勾选列表、引用、代码块、链接。**不支持图片和附件（v1）。**
- 存储：正文序列化为 **Markdown** 存入 `memos.content`（tiptap-markdown 或同类方案），保证往返不丢格式（以上列出的格式需有往返单测）。
- 自动保存：停止输入 500ms 后保存，无保存按钮；切换/关闭时立即保存。
- 字段：标题（空标题时列表显示正文首行）、正文、置顶、标签（多个，自由输入，有已用标签补全）。
- 排序：置顶在前，其余按 `updated_at` 倒序。
- 搜索：标题 + 正文 + 标签，忽略大小写；可按标签筛选。
- 删除：进回收站（见 §8）。

## 5. 日程

### 5.1 视图

- 月 / 周 / 日 三种视图，默认周视图；**每周从周一开始**。
- 点击空白格新建；拖动改时间；拖动边缘改时长（周/日视图）。
- 不显示农历与法定节假日（v1）。

### 5.2 字段

标题、开始、结束、全天、备注、颜色（6 个预设色）、重复、提前提醒。

### 5.3 重复规则

- 预设：不重复、每天、工作日（周一至五）、每周（可多选星期）、每月（按日期）、每年。
- 结束条件：永不 / 到某日 / 共 N 次。
- 以 RFC 5545 RRULE 存储，用 `rrule` 库展开。

### 5.4 修改/删除重复日程

修改或删除重复日程的某个实例时弹窗选择：**仅此次 / 此后全部 / 全部**。

| 选择           | 实现                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 仅此次（修改） | 新建一条例外日程：`recurrence_id` 指向原日程，`original_start_at` 记原实例开始时间；原日程 `exdates` 加入该时间                |
| 仅此次（删除） | 原日程 `exdates` 加入该实例时间                                                                                                |
| 此后全部       | 原日程 RRULE 加 `UNTIL` 截断到该实例之前；从该实例起复制成一条新重复日程并应用修改；原日程在截断点之后的例外日程一并迁移或删除 |
| 全部           | 直接改原日程；时间改动时已有例外保留                                                                                           |

### 5.5 提前提醒（与提醒事项联动）

- 选项：不提醒（**默认**）、准时、提前 5 / 10 / 15 / 30 分钟、1 小时、1 天。
- 设置后**自动生成一条关联提醒事项**（`reminders.event_id` = 日程 id，`source='event'`），标题同日程，`due_at = start_at - 提前量`。
- 重复日程：关联提醒也带相应 RRULE（与日程同步），并遵守 `exdates`。
- 联动：改日程时间/标题/重复 → 同步更新关联提醒；删日程 → 关联提醒一并软删除；取消提前提醒 → 删除关联提醒。
- 关联提醒在提醒页中显示日程图标，编辑时提示「此提醒由日程生成，请在日程中修改时间」。

## 6. 提醒事项

- 分组（左侧）：**今天 / 计划中 / 全部 / 已完成**。不支持自定义清单（v1）。
  - 今天：今天到期 + 逾期未完成；计划中：有 `due_at` 的未完成；全部：所有未完成（含无时间待办）；已完成：按完成时间倒序。
- 字段：标题、备注、到期时间（可空 = 普通待办）、重复、优先级（无/低/中/高）。
- 勾选即完成；重复提醒完成后自动生成下一次（推进 `due_at`，清空 `notified_at`）。
- 到点弹 Windows 系统通知：标题 + 备注首行。通知按钮「完成」「稍后 10 分钟」——**若 Tauri 通知插件在 Windows 上不支持动作按钮，则点击通知打开应用并定位到该提醒，在应用内提供这两个按钮**，并在 PR 说明中写明采用了哪种。
- 贪睡固定 **10 分钟**：写 `snooze_until = now + 10min`。
- 错过补发：启动时若有关机期间到期且未通知的提醒，合并为一条通知「你有 N 条错过的提醒」，点击打开「今天」页。

## 7. 托盘、自启、快捷键

- 关闭窗口 = 隐藏到托盘，不退出。托盘菜单：打开 WorkBench / 新建提醒 / 退出。双击托盘图标打开主窗口。
- 开机自启：**默认关闭**，设置页可开关。用户**首次**创建带时间的提醒（或带提前提醒的日程）时，弹一次提示：「开启开机自启，重启电脑后提醒才能准时？」[开启] [暂不]，只提示一次（记在 settings）。
- 全局快捷键 **Ctrl+Alt+N**（设置页可改；注册失败时提示冲突）：呼出小型「快速新建」窗口（置顶、居中、Esc 关闭），类型切换 备忘 / 日程 / 提醒，回车保存。

## 8. 回收站

- 删除 = 软删除（写 `deleted_at`），进回收站；回收站集中展示三类已删除内容，可恢复或「永久删除」。
- **30 天自动清理**：启动时及每天一次，对 `deleted_at` 早于 30 天的记录**清空内容字段但保留行与 `deleted_at`**（墓碑，供日后同步）。「永久删除」同样只清空内容。
- 删除日程时关联提醒一起进回收站，恢复日程时一起恢复。

## 9. 设置（综合工作台相关）

主题（跟随系统/浅/深）、开机自启、全局快捷键、日程默认提前提醒（默认「不提醒」）。

## 10. 数据表改动（相对 ARCHITECTURE.md §4）

```sql
-- events 新增
exdates TEXT NOT NULL DEFAULT '[]',        -- JSON 数组，被跳过的实例开始时间（毫秒）
recurrence_id TEXT,                        -- 例外日程指向原重复日程 id
original_start_at INTEGER,                 -- 例外日程对应的原实例开始时间
remind_before_minutes INTEGER,             -- NULL = 不提醒；0 = 准时
-- reminders 新增
source TEXT NOT NULL DEFAULT 'manual',     -- 'manual' | 'event'
-- 索引
CREATE INDEX idx_events_range ON events(start_at, end_at) WHERE deleted_at IS NULL;
CREATE INDEX idx_reminders_event ON reminders(event_id) WHERE deleted_at IS NULL;
```

settings（kv）新增键：`theme`、`autostart_prompted`、`global_shortcut`、`default_event_remind`、`last_trash_purge_at`。

## 11. v1 不做

同步、图片/附件、协作共享、ICS 导入导出、农历与节假日、自定义清单、多档贪睡。

## 12. 验收标准

1. 备忘录：新建、所见即所得编辑、自动保存、置顶、标签、搜索可用；重启后格式不丢。
2. 日程：月/周/日视图切换；拖动改时间；创建每周重复日程后，分别执行「仅此次 / 此后 / 全部」的修改与删除，结果正确。
3. 日程设提前 10 分钟 → 提醒页出现关联提醒；改日程时间后提醒时间同步；删日程后提醒消失。
4. 提醒：到点 ±30 秒内弹系统通知；「稍后 10 分钟」生效；重复提醒完成后生成下一次；同一提醒不重复弹。
5. 关窗进托盘，托盘菜单三项可用；关机期间错过的提醒启动时合并补发。
6. 首次建带时间的提醒时弹自启提示，只弹一次；默认未开启自启。
7. Ctrl+Alt+N 在应用隐藏时也能呼出快速新建并保存。
8. 删除进回收站可恢复；把 `deleted_at` 改到 31 天前后，清理任务清空内容但保留墓碑。
9. 「今天」页三个区块数据正确，跨午夜自动刷新。
10. 仓库层、重复规则展开与例外、调度器（假时间）、回收站清理、Markdown 往返均有 Vitest 单测；`pnpm lint / typecheck / test`、CI 全绿。
