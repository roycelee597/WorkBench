# 模块运行时（P0-1、P0-2）

## 范围

综合工作台和 AI 工作台是核心功能。入口可在设置中隐藏或重新显示，两个核心工作台均不可卸载。可安装、可卸载的模块包括金融、后续的 CS2 和第三方模块。P0-1 提供模块运行时和番茄钟样例，P0-2 接入官方金融包。

AI 引用的模块未安装或已卸载时，引用处显示「未安装」。

V1 从本地选择 ZIP 格式的 `.wbpkg` 安装。包包含已构建的静态前端，可带 Windows 本地引擎。应用不提供在线下载或市场。

## 包与授权

根目录 `manifest.json` 声明反向域名 ID、名称、SemVer 版本、相对 HTML 入口、最低宿主版本和已知权限。可选字段包括描述、作者、图标、许可证及主页。路径只用可移植的 ASCII 相对路径，拒绝父目录、绝对路径、Windows 保留名称和其他歧义形式。

可选 `engine` 声明 `path`、64 位十六进制 `sha256`、并发上限 `concurrency`（1–8）。引擎属于**完全信任**级别，以当前用户身份运行，可在操作系统权限内访问本机。安装确认醒目标明这一点，列出权限、模块 ID、版本和引擎摘要。SHA-256 在验包和每次运行前检查，用于验证文件一致性。

可选 `uninstall` 声明 `credentials`（含 `service`、`account` 的列表）、`tables`、`settingsPrefixes`。Windows 凭据服务加宿主 identifier 和模块 ID 前缀。`tables` 与 `settingsPrefixes` 仅用于声明和展示，普通模块随私有目录整体清理。模块包无权指定主程序数据表、系统快捷键或他人凭据为清理目标。

安装预检、确认和提交使用同一份暂存包。拒绝未知权限、不兼容版本、重名文件、路径穿越、链接、保留设备名、超过 2,048 个归档条目或解压后超过 256 MiB 的包。已安装模块的同 ID 包须先卸载。校验完成的目录以同卷原子改名发布到 `modules/<id>/<version>`。权限由用户确认授予，可在设置撤销。新请求以最新授权为准，撤销引擎权限会结束活动任务。

## 隔离与 SDK

包内资源经 `wbpkg://<id>/<path>` 自定义协议读取，Windows WebView2 使用 Tauri 的 `http://wbpkg.localhost/` 映射，路径含 ID 和随机路由凭证。协议只读，限定已安装包目录。iframe 使用 `sandbox="allow-scripts allow-forms"`，具有不透明来源。CSP 限制脚本、样式、图片到本包及必要的图片数据，禁用网络连接、表单提交、嵌套 frame、worker、对象和 base URL。主窗口只允许包协议作为模块 frame 来源。包来源没有 Tauri capability。

`@workbench/sdk` 通过 `postMessage` 发送 `workbench-module-v1` 消息。请求带 ID、方法、参数及 iframe 会话凭证。宿主按 `event.source` 识别已挂载 iframe，核对不透明来源及凭证，检查实时授权，再用 zod 校验参数。请求和事件使用转交的 MessagePort，异步响应不会交给导航后的页面。SDK 提供超时、带代码的错误、事件订阅及取消订阅。

SDK API 见架构 §6.2。每模块独享按 UTF-8 编码计量的 10 MiB JSON storage。宿主序列化写入并限制通知、写入、交互与引擎请求频率。共享资源读写经宿主仓库，修改或删除只允许操作模块自己创建的记录。撤销权限后，到达的相关请求返回权限错误。

## 引擎任务

`engine.start({ input, paths?, execPaths? })` 启动 manifest 指定的固定文件，向 stdin 写一行 JSON，包含输入和本次获准路径。主程序解析 `dialog.open` 返回的短时模块专属路径句柄，调用方不能自行声明路径。将所选路径作为 `execPaths` 使用还需 `engine.exec_paths` 权限及一次宿主确认。普通 `input` 是业务 JSON。引擎在模块私有目录运行，模块负责遵循 stdin 与路径约定。

stdout 使用金融 sidecar 的 JSON Lines 约定。进度和结果用带 `type` 的对象，失败先输出 `error` 行再退出。`engine.progress({ taskId })` 查询隔离的状态，`engine.logs({ taskId })` 读取宿主统一脱敏后的有界日志，`engine.cancel({ taskId })` 结束整个 Windows Job 进程树，`engine.probe()` 校验可启动条件及引擎摘要。宿主限制单行、日志和任务留存量，引擎不继承宿主的 token 或 API key 环境，日志不回显 stderr 或任意引擎字段。

进度返回 `done`、`current` 和 `total`。错误返回通过 `[A-Z_]{1,40}` 校验的错误码，以及长度受限并脱敏的消息。官方金融宿主适配器从当前 identifier 对应的系统凭据读取 token，只向引擎 stdin 传递。普通模块无法请求这一适配器或取得 token。

## 卸载与官方模块

宿主确认框列出模块文件、引擎、缓存、storage、凭据、模块私有数据库及共享记录、设置项、快捷键和 AI 动作。确认后持久化「清理中」，立即停用 frame 和权限，停止引擎及注销宿主管理的注册。删除模块文件和私有状态，清除声明的 Windows 凭据，按模块所有权清空宿主仓库的内容，保留共享业务记录的最小同步墓碑。全部成功后才移除清理记录。步骤须幂等，失败后在重启时继续，清理完成前禁止加载及同 ID 重装。P0-1 不开放快捷键与 AI 动作注册，官方迁移适配器负责将二者的注销纳入清理。

官方金融 `.wbpkg` 随正式安装包提供。P0-2 由宿主提供版本化的官方模块描述、迁移及注销适配器，首次升级自动接入金融模块并原样保留现有数据与 token。官方包来自安装包内部资源及宿主允许列表，用户选取的同 ID 包不能冒充官方模块。卸载后记录用户选择，避免下次启动自动恢复。设置页可从附带资源一键重新安装，沿用校验流程。卸载清除的数据和 token 无法通过重新安装恢复。

P0-2 金融包位于安装资源的 `official/finance.wbpkg`。首次安装以已校验的包目录原子改名为完成点，旧缓存、阈值、游标、设置和系统凭据原位接管，重试不重复写入它们。卸载一经请求先拦截尚未执行的模块写入，并等待正在执行的写入结束，再进入持久化清理。金融专用行由宿主以固定事务清除，保留空表供重装使用。通用共享仓库按所有权清理金融提醒并保留最小墓碑。金融包的 `tables` 和 `settingsPrefixes` 声明供确认展示，主库清理范围由宿主固定。

后续迁移只在宿主侧注册，沿用以下接口边界。包清单不能声明这些钩子。

| 宿主接口                       | 输入与完成条件                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `OfficialModuleDescriptor`     | 官方模块的保留 ID、安装包内的相对资源路径、迁移版本，以及宿主提供的迁移和注销适配器。                                                       |
| `migrateLegacy(context)`       | 上下文仅含对应模块的旧资源与私有落位目标。版本化、可重试，在所有数据和凭据接管完成后才切换入口。保留已有数据和 token；不把 token 交给前端。 |
| `removeRegistrations(context)` | 按宿主管理的模块所有权注销快捷键与 AI 动作。幂等，清理失败保留卸载日志。                                                                    |
| `reinstallBundled(id)`         | 仅从受信官方目录取得当前附带包，走同一预检与安装流程。成功后清除「已卸载」选择。                                                            |
