# WorkBench 桌面端

由 Tauri 2 官方 `create-tauri-app@4.7.5` 的 `react-ts` 模板生成，使用 React、TypeScript 和 Vite。

当前只显示骨架页面。产品名称为 WorkBench，应用标识为 `com.royce.workbench`。

请在仓库根目录安装依赖并运行：

```powershell
pnpm install --frozen-lockfile
pnpm --filter desktop tauri dev
```

目录与开发约定见根目录的 `ARCHITECTURE.md`、`AGENTS.md` 和 `CONTRIBUTING.md`。
